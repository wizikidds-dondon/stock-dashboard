📖 使用說明

如何取得 Telegram Bot Token 1. 在 Telegram 搜尋 @BotFather
2. 輸入 /newbot，依指示建立 Bot
3. 複製取得的 Token 貼入上方設定
如何取得 Chat ID 1. 將 Bot 加入目標群組或頻道
2. 傳送任意訊息給 Bot
3. 開啟瀏覽器：api.telegram.org/bot[TOKEN]/getUpdates
4. 在回應中找到 chat.id
